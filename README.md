# Circuit Coach

A practice page for Unit 1.3, series and parallel circuits, for M3 science classes
(English programme). 12 questions, 24 answer parts, hints, worked steps and a calculator.

- `index.html` - the page the students use. Pressing **Submit** saves their result
  automatically to the teacher's Google Sheet.
- `teacher.html` - the results page. It only works with the teacher's secret key.

Students never see each other's results. The pages hold no names, no email addresses
and no passwords - only a class, a student number and a nickname.
